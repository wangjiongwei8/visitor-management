# 访客管理系统 V2 — 操作说明书

> 适用对象：系统的最终使用者（访客、被访人员工、门卫、管理员）。
> 本系统支持「访客扫固定二维码自助预约 → 被访人审核 → 门卫签到发牌」全流程，零外部依赖。

## 一、系统概述与角色说明

访客管理系统 V2 用于企业访客出入管理。核心流程：
1. **访客**在门卫处扫描固定二维码，手机填写预约表单（无需登录）。
2. 预约提交后，根据**审核开关**决定走向：
   - 开关**关闭**：自动通过（状态 `scheduled`）。
   - 开关**开启**：进入待审核（`pending`），由**被访人（员工）本人**审核通过或拒绝。
3. **门卫**在访客到访时搜索并签到、签退，系统自动发放对应颜色通行牌，黑名单自动拦截。

| 角色 | 登录入口 | 主要职责 |
|------|----------|----------|
| 访客 | 扫码进入，无需登录 | 填写预约 |
| 被访人（员工） | 后台登录 | 审核来访自己的预约 |
| 门卫 | 后台登录 | 签到 / 签退、发牌 |
| 管理员 | 后台登录 | 系统全部配置与数据管理 |

> 登录地址：`/login`（Docker 部署通常为 `http://<服务器>:4000/login`）。访客预约页为 `/public/appointment`，由固定二维码指向。

## 二、访客操作

**场景**：到访企业，在门卫处 / 厂区入口扫描固定二维码。

操作步骤：
1. 使用微信或浏览器**扫描固定通用二维码**，自动打开预约表单页（无需登录）。
2. 选择**访客类型**（客户 / 供应商 / 应聘者 / 送货人员 / 政府人员 / 参观访客）。
3. 填写个人信息：姓名、电话、身份证号（选填）、公司 / 单位。
4. 填写**受访人**：
   - 在「受访人」输入框中输入姓名，系统实时从受访人清单中匹配；
   - **必须从下拉清单中选定一名受访人**。若输入的姓名不在清单中，系统将阻止提交，并提示联系管理员添加受访人。
   > ⚠️ 关键：未从清单下拉选定受访人，预约无法提交。
5. 填写来访事由、预约日期、入场 / 离场时间。
6. （可选）添加随行人员、填写车牌号、选择是否就餐。
7. 点击「提交预约」。
8. 提交后页面显示预约编号与提交结果：
   - 若审核开关**开启**：显示「请等待受访人审批」，状态为待审核。
   - 若审核开关**关闭**：显示「预约成功」，状态为已通过，可直接到访。
9. 审核通过后，按约定时间到访，由门卫完成签到。

## 三、被访人（员工）操作

**场景**：有访客预约来访自己，需审核。

操作步骤：
1. 使用员工账号登录后台，进入「**我的预约**」页面。
2. 切换至「**待审核**」标签页（仅当审核开关开启、且存在待自己审核的预约时显示）。
   > 说明：列表仅显示「受访人 = 当前登录员工」的待审核预约，不会看到他人的预约。
3. 对每条预约选择：
   - **通过**：预约状态转为「已通过（`scheduled`）」，访客可到访并由门卫签到。
   - **拒绝**：直接拒绝，预约状态转为「已拒绝（`rejected`）」。**拒绝时无需填写原因**。
   > 说明：被访人仅可「通过 / 拒绝」，不可修改预约内容（如来访时间）。
4. 在「我的预约」其他标签页可查看自己相关的全部预约记录与状态。

## 四、门卫操作

**场景**：访客到访时，负责签到、签退与发牌。

操作步骤：
1. 使用门卫账号登录后台，进入「**访客签到**」页面。
2. 在搜索框输入任一信息：**手机号 / 姓名 / 车牌号 / 访客编号**，点击搜索。
   - 系统返回匹配的预约（脱敏展示，如 `张*`、`138****8000`）。
   - 若命中**黑名单**，页面以醒目红色提示拦截，**不可签到**。
   - 已拒绝（`rejected`）的预约不在搜索结果中。
3. 确认身份无误后，点击「**确认签到**」：
   - 系统按**访客类型自动匹配对应颜色通行牌**（含车辆证情况，见 5.6 节对照表），无需手动选择。
   - 状态转为「已签到（`checked_in`）」，记录签到时间。
4. 访客离场时，进入「**访客签退**」页面：
   - 搜索在厂访客 → 确认签退 → 回收通行牌。
   - 状态转为「已签退（`checked_out`）」，记录签退时间。

> 关键注意：黑名单访客系统自动拦截；通行牌颜色由系统按访客类型自动发放，门卫按颜色发牌即可。

## 五、管理员操作

管理员拥有全部后台权限，主要功能如下：

### 5.1 审核开关设置（重点）
- 路径：后台「**系统设置**」→ 审核配置。
- 开关 `review_enabled`：**开启**后访客预约进入被访人审核流程；**关闭**后访客提交即自动通过。
- 默认值为**开启（true）**，安全优先。低风险时段可临时关闭以简化流程，高风险时段建议开启。
  > 注意：开关仅影响**新提交**的预约；关闭前已处于待审核（`pending`）的旧预约不会被自动通过。

### 5.2 用户管理
- 路径：后台「**用户管理**」。
- 功能：新增 / 编辑 / 停用用户，配置角色（管理员 / 门卫 / 员工）。
- **批量导入**：下载 CSV 模板（字段：角色, 工号, 姓名, 部门），填写后上传导入；系统自动检测重复工号，并为新用户分配默认密码（首次登录强制修改）。

### 5.3 黑名单管理
- 路径：后台「**黑名单**」。
- 添加黑名单（姓名、身份证号、手机号、原因），支持**永久**或**临时（到期自动解除）**。
- 黑名单人员在门卫签到时自动拦截。

### 5.4 长约车辆与人员管理
- 路径：后台「**长约车辆 / 人员**」。
- 维护长期往来的车辆与人员：增删改查、启用 / 停用、有效期管理、在厂状态查看、编号管理。
- 长约人员 / 车辆信息**不脱敏**，便于门卫核对真实信息。

### 5.5 受访人清单维护
- 路径：后台「**受访人清单**」（host_contacts）。
- 维护可供访客填表时匹配的员工名单（姓名、部门等）。
- ⚠️ 重要：访客必须从该清单下拉选定受访人才能提交预约。新员工入职后请及时在此添加，否则访客无法预约该员工。

### 5.6 访客类型与通行牌对照
系统按访客类型自动匹配通行牌颜色与车辆证，并限定活动区域，规则如下（系统已实现）：

| 访客类型 | 通行牌颜色 | 车辆证 | 活动区域 |
|----------|------------|--------|----------|
| 客户 | 绿色 | 无车辆证 | 客户停车区 / 会议室 / 展厅 |
| 供应商 | 黄色 | 黄色车辆证 | 访客停车区 / 会议室 |
| 应聘者 | 红色 | 无车辆证 | 面试室 / 等候区 |
| 送货人员 | 红色 | 红色车辆证 | 货物收发区 / 卸货区 |
| 政府人员 | 黄色 | 黄色车辆证 | 访客停车区 / 会议室 |
| 参观访客 | 黄色 | 无车辆证 | 指定区域 |

- 门卫签到时系统按上表自动发放对应颜色通行牌（含车辆证情况），无需手动选择。
- 管理员可在系统中维护「访客类型 ↔ 通行牌颜色 / 车辆证 / 活动区域」的对照关系，确保门卫按颜色与区域准确发牌、引导。

### 5.7 二维码管理
- 路径：后台「**二维码管理**」。
- 生成 / 下载指向 `/public/appointment` 的固定二维码图片，可打印张贴于门卫处或厂区入口。

### 5.8 密码策略
- 路径：后台「**密码策略**」。
- 配置密码复杂度要求、有效期、锁定规则等，约束所有账号。

### 5.9 操作日志
- 路径：后台「**操作日志**」。
- 记录全量关键操作（操作人、类型、模块、描述、时间、IP），支持多维度筛选，用于审计追溯。

### 5.10 访客看板
- 路径：后台「**访客看板**」。
- 统计卡片（预约总数 / 签到 / 在厂等）+ 图表（来访目的分布 / 类型分布 / 趋势），支持时间范围与接待人筛选。

### 5.11 预约管理
- 路径：后台「**预约管理**」。
- 查询（按时间 / 状态 / 访客类型等筛选）、查看详情、修改预约、导出（CSV / Excel）。

## 六、通用注意事项与常见问题

- **访客无需登录**：访客全程通过扫码填表完成预约，不使用后台账号。
- **受访人必须选定**：未从清单下拉选定受访人，提交将被阻止。
- **审核开关影响新预约**：关闭后新提交自动通过；已 `pending` 的旧预约不受影响。
- **拒绝无需原因**：被访人可直接拒绝，系统不强制填写原因。
- **黑名单自动拦截**：门卫签到时命中黑名单将拦截，不可放行。
- **数据脱敏**：列表与详情中姓名、手机、身份证脱敏展示（如 `张*`、`138****8000`）；长约车辆 / 人员不脱敏。
- **默认账号及时改密**：首次登录强制修改密码；生产环境请立即修改 admin / security / employee / visitor 全部默认密码。
